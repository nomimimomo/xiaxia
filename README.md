# 鲜虾 1.6

覆盖原鲜虾目录安装，不要同时启用多份。升级前可在“我”导出聊天备份。

## 本次修正

- 依据用户提供的鱼板面代码，测量酒馆顶栏和输入栏，窗口位于两者之间；按实际渲染比例修正主题缩放及坐标。手机跟随可见视口。上一版仅使用宽高上限，未完整接入定位，本版补齐。
- 搜索框固定为 28px 高，左右留边；桌面会话栏 210px，缩小输入区和按钮，让出正文空间。
- 上拉刷新支持从列表中段滚到底后继续上拉；显示“继续上拉 / 松开刷新”，可直接点击底部刷新。取消、横向滑动、距离不足不触发。
- 朋友圈和公众号默认各保留 20 条。旧默认 200 会迁移到 20，其他自定义值保留；下一次成功刷新对应信息流时清理旧条目，不在打开窗口时删除。
- 每个聊天默认保留 200 个气泡，用户消息和 AI 消息都各算一个。成功收到回复后清理；失败和待发消息暂时保留，可能超过上限。可在“我 → 预设与 API”修改。发送给模型的历史条数是独立设置。

## 回复与人设

参考用户“无有居茶馆 / 群聊状态栏”里的短句分行、多人接话、具体讨论正文高光与槽点。
一次回复可产生多个短气泡；文本按换行及句读拆分，选项和文件卡片保持完整。群聊开放话题要求相关成员交替接话，不固定只由一个人包办；点名时允许被点名成员先回答。实际输出仍取决于模型及预设。

修复了混合群聊中角色未绑定预设时可能遗漏当前预设的问题。绑定人格继续使用其对应预设快照；未绑定成员使用当前所选预设。保持原有条目顺序和启用状态。
角色成员在发起请求时按角色文件身份重新读取，发送描述、性格、场景、开场、示例对话、角色系统提示、后置提示、深度提示和启用的内嵌世界书条目。角色卡不可用时提示错误，不拿别的角色代替。角色保留自身知识和关系边界，不再统一被要求扮演元认知点评助手。
角色卡字段以成员资料发送，并非完整复刻酒馆主聊天的注入深度和复杂宏执行机制。

日志新增实际预设条目数、预设来源数、角色卡数、发言成员数、气泡数、清理数、上拉事件和窗口尺寸；不记录人设正文、聊天内容、密钥或来源网址。“我 → 错误报告”可导出。

## 阅读应用

书架提供“晋江文学城”和“夸克网盘”入口，无需手填名称、封面。其他网站只需粘贴地址，名称/封面/分组收进选填项。
这些入口打开平台网页，账号在原站登录。网站允许时在鲜虾窗口显示，禁止内嵌或登录受限时点“原站打开”。夸克网盘不等于夸克浏览器，也无法获取夸克浏览器里任意第三方网站的书架。
本版未实现平台账户书架自动拉取、平台阅读进度同步、官方小程序或服务号注册。普通网页封装成应用入口不会自动获得平台账号接口权限。
临时阅读、手动记录章节、摘抄沿用 1.5。临时正文关闭窗口后清空；只保存选中的摘抄、来源与阅读记录。
