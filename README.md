# 鲜虾 1.5

本版是网页书架基础版。覆盖原鲜虾目录安装，不要同时启用多个版本；先备份原目录及数据。

## 本次变更
- 参考鱼板面：桌面最大 680 × 680，手机最大 620 × 620；手机宽留 20px、高留 28px，跟随可见视口缩放。
- 修正多个导航共享 tab 忙碌状态而一起转圈的问题；这不等于已解决所有宿主页刷新原因。
- 书架 → 加网页：保存书名、封面地址、来源链接。兼容普通 http/https 阅读网址，包括夸克中打开的第三方网址。
- 打开网页书籍后，可尝试内嵌原站；无法显示或登录时点“原站打开”。不是完整浏览器，不共享夸克 App 的登录状态。
- “记进度”手动保存当前章节和章节地址，只在鲜虾保存，不同步平台账户。内嵌网页跳转后的地址无法自动读取。
- “粘贴阅读”接受用户复制的本章文字，以鲜虾排版临时阅读。正文只在内存，关闭窗口后清空；不下载整本书。
- “摘抄”支持临时阅读页选中文字后保存；原站内容需手动复制。摘抄保存书名、章节、来源 URL 与笔记。可选当前浏览器或酒馆账户。
- 新增网页操作日志，不记录正文和来源地址；“我 → 错误报告”导出。
- 聊天沿用 1.4：发送/Enter 逐条入聊天，接收回复合并当前待回复消息请求。真实接口请求失败仍需错误报告定位。

## 参考与实现边界
- Obsidian Web Clipper：https://github.com/obsidianmd/obsidian-clipper （参考摘抄与出处交互，未复制代码）
- Mozilla Readability：https://github.com/mozilla/readability （调研正文提取，本版未集成）
- MDN X-Frame-Options：https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/X-Frame-Options
- 鱼板面用户提供源码：沿用其窗口尺寸规则。

网站可能禁止 iframe 或第三方登录。本版未验证晋江/夸克真实账户，无官方账号接口、平台进度同步或自动跨站正文获取。原文件书籍解析仍未接入。

验证：35 项 Node 测试通过；本轮浏览器运行因 Chromium 缺失、补装审批服务限流未完成。手机布局及平台登录需要实际环境复核。

# 鲜虾 1.4

将安装包内 shrimp 文件夹中的内容覆盖到原扩展目录，再刷新酒馆。保留原扩展文件夹名称；不要另装第二份。

## 聊天
- 输入文字后点“发送”或按回车，只增加一条气泡。可以连续发送多条。
- 点“接收回复”，把当前待回复消息一起交给 AI。该按钮转圈时正在请求。
- Shift+Enter 换行。失败消息旁的红色感叹号可重试。
- 名片和文风文件也先加入聊天，点“接收回复”后一起提交。

## 本次调整
- 恢复气泡发送与请求回复分离。等待回复时可以继续追加下一批消息。
- 自定义 API 过滤空消息，合并相邻同角色消息，保留内容顺序；输出上限转为数字。
- API 失败显示结构化错误说明，隐藏已知密钥、地址和请求正文后写入错误报告。
- 隔离鲜虾点击、键盘和提交事件；保留导航容器，书架显示读取状态，记录读取和页面离开事件。
- 安装包移除开发测试及旧更新说明，保留运行依赖和许可。

## 验证范围
自动化测试及模拟酒馆浏览器交互验证通过。未连接用户实际 API；400 的具体原因尚未确认。整页刷新未在模拟环境复现，不能宣称已根治。若仍失败，请从“我 → 错误报告”导出本次报告。

## 阅读
现阶段支持书籍原文件保存、书架整理、双向迁移、摘抄及 TXT 导入导出；正文解析与阅读待合并鱼板面接入。
